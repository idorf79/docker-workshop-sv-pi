# Requirements

## Photo manager - The Big Picture:


- Upload pictures from phone
- Different formats JPEG, RAW, HEIC
- Add photos trough:
    - USB
    - SFTP
- Watch pictures
- Select photos based on:
    - Date and/or time
    - Size
    - Location
    - Tags
    - Color
- User can make albums
- User can make changes:
    - Rotate
    - Tag
    - Location
- Backup feature
- Album download
- Access through:
    - Web browser
    - Network
        - Samba
        - NFS
    - TV
- Add AI to identify persons, objects and animals
